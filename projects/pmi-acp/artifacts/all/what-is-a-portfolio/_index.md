# What is a Portfolio?

## 📝 CUE & NOTES

| CUE | EN | VI |
|---|---|---|
| **What is it?** | A **collection of projects, programs, subsidiary portfolios, and operations** managed as a group to achieve **strategic business objectives**. | Tập hợp **các dự án, chương trình, danh mục con và hoạt động vận hành** được quản lý theo nhóm để đạt **mục tiêu chiến lược kinh doanh**. |
| **What is it used for?** | Aligns organizational resources (projects & programs) to **long-term strategic goals** (3–5 years). Ensures every initiative contributes to the big picture. | Căn chỉnh nguồn lực tổ chức (dự án & chương trình) với **mục tiêu chiến lược dài hạn** (3–5 năm). Đảm bảo mọi sáng kiến đóng góp vào bức tranh lớn. |
| **When to use?** | When an organization needs to coordinate **multiple programs and projects** to achieve a single strategic objective (e.g. increase revenue by 50%). | Khi tổ chức cần phối hợp **nhiều chương trình và dự án** để đạt một mục tiêu chiến lược duy nhất (vd: tăng doanh thu 50%). |
| **Key Points** | 1. Portfolio sits at the **top of the hierarchy**: Portfolio → Program → Project. 2. Strategic goals = **3–5 year long-term goals**. 3. Portfolio manager works at the **highest level**, often with CEO/board. 4. A portfolio can contain programs, standalone projects, AND operations. 5. Portfolio manager's job: look at strategic goals → identify which programs/projects to run. | 1. Portfolio ở **đỉnh hệ thống phân cấp**: Portfolio → Program → Project. 2. Mục tiêu chiến lược = **mục tiêu dài hạn 3–5 năm**. 3. Portfolio manager làm việc ở **cấp cao nhất**, thường với CEO/hội đồng. 4. Portfolio có thể chứa programs, projects độc lập VÀ cả operations. 5. Công việc portfolio manager: nhìn vào mục tiêu chiến lược → xác định programs/projects cần thực hiện. |
| **Mental Model** | Portfolio = **Master plan for a city**: the mayor (portfolio manager) looks at the city's 5-year vision, then decides which roads (programs), buildings (projects), and services (operations) to build — all to serve that one big vision. | Portfolio = **Quy hoạch tổng thể một thành phố**: thị trưởng (portfolio manager) nhìn vào tầm nhìn 5 năm, rồi quyết định xây đường nào (programs), tòa nhà nào (projects), dịch vụ nào (operations) — tất cả phục vụ tầm nhìn lớn đó. |
| **Connections** | **Project** (temporary, unique output) → grouped into **Program** (related projects with shared benefit) → grouped into **Portfolio** (strategic alignment). Portfolio ≠ Program: program groups *related* projects; portfolio groups *anything* that serves a strategic goal. | **Project** (tạm thời, đầu ra độc đáo) → nhóm thành **Program** (các dự án liên quan có lợi ích chung) → nhóm thành **Portfolio** (căn chỉnh chiến lược). Portfolio ≠ Program: program nhóm các dự án *liên quan*; portfolio nhóm *bất cứ thứ gì* phục vụ mục tiêu chiến lược. |
| **Real-world Example** | Toyota wants 50% revenue increase (strategic goal). Portfolio contains: Program 1 (new car model A), Program 2 (new car model B), Project (update existing models), Project (new sales incentive program). All managed together = the portfolio. | Toyota muốn tăng doanh thu 50% (mục tiêu chiến lược). Portfolio gồm: Program 1 (mẫu xe mới A), Program 2 (mẫu xe mới B), Project (cập nhật các mẫu hiện có), Project (chương trình khuyến mãi bán hàng mới). Tất cả quản lý cùng nhau = portfolio. |
| **Pitfalls** | • Confusing portfolio with program — portfolio aligns to **strategy**; program aligns **related projects**. • Thinking portfolio only contains projects — it also includes programs, sub-portfolios, and operations. • Portfolio manager ≠ Project manager — they operate at completely different levels. | • Nhầm portfolio với program — portfolio căn chỉnh với **chiến lược**; program căn chỉnh **các dự án liên quan**. • Nghĩ portfolio chỉ chứa projects — nó còn có programs, sub-portfolios và operations. • Portfolio manager ≠ Project manager — họ hoạt động ở các cấp hoàn toàn khác nhau. |
| **Exam Tips** | • Hierarchy to memorize: **Portfolio > Program > Project**. • Portfolio = strategic alignment (long-term, 3–5 years). • If a question describes someone working with the CEO on long-term goals → **Portfolio Manager**. • Portfolio can include projects that are NOT related to each other — they just all serve the same strategic objective. | • Hệ thống phân cấp cần nhớ: **Portfolio > Program > Project**. • Portfolio = căn chỉnh chiến lược (dài hạn, 3–5 năm). • Câu hỏi mô tả ai đó làm việc với CEO về mục tiêu dài hạn → **Portfolio Manager**. • Portfolio có thể chứa các projects KHÔNG liên quan nhau — chúng chỉ cùng phục vụ một mục tiêu chiến lược. |

## 📌 SUMMARY

| EN | VI |
|---|---|
| A **portfolio** is a collection of projects, programs, and operations managed together to achieve an organization's **strategic goals** (typically 3–5 year objectives). The **portfolio manager** works at the executive level — often alongside the CEO — to ensure every initiative aligns with the company's long-term direction. Portfolio sits at the top of the hierarchy: **Portfolio → Program → Project**. | **Portfolio** là tập hợp các projects, programs và operations được quản lý cùng nhau để đạt **mục tiêu chiến lược** của tổ chức (thường là mục tiêu 3–5 năm). **Portfolio manager** làm việc ở cấp điều hành — thường cùng với CEO — để đảm bảo mọi sáng kiến căn chỉnh với định hướng dài hạn của công ty. Portfolio ở đỉnh hệ thống: **Portfolio → Program → Project**. |
